# Slotify

Eigenständiger Musikplayer im Liquid-Glass-Design mit einstellbarem Lyrics-Tool und Spotify-OAuth-Sync.

## GitHub Actions APK-Build
1. Repository auf GitHub erstellen und alle Dateien aus diesem ZIP-Archiv in den Branch `main` hochladen.
2. Im Tab **Actions** den Workflow **Build Slotify APK** starten (oder auf den automatischen Push-Trigger warten).
3. Nach erfolgreichem Build das Artifact **`slotify-android-apk`** herunterladen, entpacken und `app-release.apk` installieren.
